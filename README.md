📰 About

Amar Ujala is a modern web-based newspaper and news experience designed around a clean, fast and responsive interface.

The project is built using React, TypeScript, Vite, Tailwind CSS and shadcn/ui, providing a modern frontend architecture for presenting newspaper and news-related content.

🚀 Getting Started

📋 Requirements

Make sure you have:

- Node.js
- npm

---

📥 Installation

1️⃣ Clone the repository

git clone https://github.com/amitbhardwaaj1/amarujala.git

2️⃣ Enter the project

cd amarujala

3️⃣ Install dependencies

npm install

4️⃣ Start development

npm run dev

The project will start on the local development server provided by Vite.

---

📦 Production Build

Create a production build:

npm run build

Preview the production build:

npm run preview
